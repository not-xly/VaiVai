# Vai Vai

Diccionario español ⇄ italiano para iPhone (PWA, funciona sin conexión): traducir palabras y frases, conjugar verbos italianos, guardar favoritos y hacer ejercicios.

Datos: diccionario offline a partir de Wiktionary (vía kaikki.org, CC BY-SA) y FreeDict (spa-ita, ita-spa); conjugaciones comprobadas contra Wiktionary. Las frases se traducen online (Google Translate) y se guardan para usarlas después sin conexión.
